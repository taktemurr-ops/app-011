# APP-011 — Tasarruf 360 (Savings 360)

Offline-first Flutter mobile app for private savings goals, household plans and habit tracking. This repository belongs to the **400 Uygulama Projesi**, not to the 100/1500-game projects.

## What works in the source

- Create savings goals in TRY, USD or EUR with target, owner, optional date and monthly contribution plan. Currencies are **tracked separately**, never summed without a conversion rate.
- Record deposits/withdrawals, view local history, inspect per-goal progress and projected completion dates; money uses integer minor units.
- Manage manual recurring savings plans (weekly/monthly), confirm a scheduled deposit explicitly, pause/delete rules, never initiate real payments.
- Household name, per-person goals and private shared-device checklist; create a 30-day no-spend challenge.
- 20-entry offline module hub: planner, rule-based coach, analytics, challenges, local family community, lessons, calculators, journal, saving goal templates, local assistant, goals as projects, checklists, manual plans, lesson badges, household dashboard, backup studio, dashboard, minicourse, decision support and offline advanced toolkit.
- Offline savings academy and mini-course with a completion badge, four template packs and a scenario calculator.
- Arabic / English / Turkish app copy and material RTL layouts, locale-aware amount entry with Arabic and Persian digits; Android and iOS Flutter source.
- Encrypted device-local storage via `flutter_secure_storage` (Android encrypted shared preferences) with write-first atomic state updates, strict JSON validation, portable manual JSON backup/import, confirmation before export or deletion.
- Automated pure Dart business-rule tests, persistence regression tests, widget smoke tests and a GitHub Actions Android debug build workflow.

## Design exclusions / release gates

This is **not** a bank, financial adviser or payment service. There is no bank API, background transfer, real social network, remote AI, cloud account, external marketplace, paid IAP, real advertising, crash analytics or push delivery. The corresponding catalog entries offer **local functional counterparts** rather than misrepresenting simulated services as real. The advanced toolkit is free and offline. Never store user secrets in GitHub.

Android and iOS release signing, store listing/screenshots, privacy disclosures, consent flows, final platform policy checks, real-device tests and any configured live integrations are **not verified by this source package**. A green GitHub Actions run verifies Dart analysis/tests and Android debug APK only, not App Store or Google Play approval. See [`docs/release-gates.md`](docs/release-gates.md).

## Build and test

```bash
flutter --version
flutter create --platforms=android,ios --project-name tasarruf_360 .
flutter pub get
dart format lib test
flutter analyze --no-fatal-infos
flutter test --coverage
flutter build apk --debug
```

Requires Flutter 3.38.0+, Dart compatible with `sdk: '>=3.5.0 <4.0.0'`, Android SDK/JDK 17 to run Android build, and macOS/Xcode for an iOS build. Platform scaffolding may be generated by `flutter create` from this source; no generated native folders are checked in. Set unique bundle IDs before store signing. **Do not** upload private JSON backups to shared repositories.

## Domain boundaries

- `lib/core/models.dart`: strict, versioned savings ledger, goals, movements, plans, checklist and financial invariants.
- `lib/core/money.dart`: localized amount parsing in integer minor units, monthly contribution and finish projections.
- `lib/core/storage.dart`: encrypted storage boundary, durable mutation queue and explicit backups.
- `lib/ui/`: responsive screens, dialogs, module hub, Turkish/English/Arabic copy.
- `test/`: business, storage, import integrity, widget smoke tests.

No app analytics, cloud sync or bank data is collected by the app code. Financial estimates exclude interest, tax, exchange rate changes and inflation.
